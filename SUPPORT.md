# Support

Metrum AI Router is an open-source project maintained on a best-effort basis.
The project does not promise response or resolution times.

## Where To Ask

- Use the question issue form for installation, configuration, and usage
  questions after checking the hosted docs and existing issues.
- Use the bug form for reproducible defects.
- Use the feature form for proposed product or documentation improvements.
- Report vulnerabilities only through the private path in
  [SECURITY.md](SECURITY.md).

Public issues must not contain provider keys, caller tokens, token hashes,
credentials, prompts, raw images, customer data, private hostnames, or full
production configuration. Reduce examples to placeholder-based reproductions
and safe scalar diagnostics such as versions, status codes, and sanitized error
classes.

Project issue triage, troubleshooting suggestions, and accepted patches do not
create a support contract or operational responsibility for a deployment.
Operators remain responsible for backups, upgrades, rollback, credentials,
provider accounts, infrastructure, and incident response for self-managed
installations.

## Ownership And Contact

Chetan Gadgil is the approved community and support owner. Public project
questions use the GitHub issue forms linked above. Private commercial or
deployment inquiries may use the [Metrum website](https://www.metrum.ai) or
[contact@metrum.ai](mailto:contact@metrum.ai), and
security reports must use the separate private path in
[SECURITY.md](SECURITY.md). An owner assignment does not promise continuous
availability or a response time; any time-bounded launch coverage must be
explicitly confirmed in the applicable launch evidence record.
